# Brand kit pilot

Quality Engineering is the first pilot. Quality Engineering builds tools for, and performs, quality assurance and testing for video games.

The user’s requested system includes primary and secondary lockups, standalone marks, wordmarks, color variants, palettes with print/digital values, type hierarchy, patterns, supporting icons/illustration, usage rules and practical applications. Preserve supplied identities; proposed extensions must be marked as drafts. Do not infer original fonts or fabricate Pantone/CMYK specifications.

The pilot lives at /brand/quality-engineering, directly reviewable and excluded from search indexing. The homepage carousel remains view-only; it does not link to this kit.
